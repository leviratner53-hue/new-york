# new-york
## Кошелёк — `wallet/`

Личный учёт расходов (PWA): счета с балансами, траты за период по каждому счёту,
бюджеты по категориям с дневным лимитом, подписки и регулярные платежи, статистика.
Данные хранятся на устройстве (localStorage), есть резервная копия в JSON и выгрузка в CSV.

Установка на iPhone: открыть `…/wallet/` в Safari → «Поделиться» → «На экран „Домой“».

## Английский — `english/`

Проверка уровня английского и программа обучения по её результатам (PWA).

- **Тест уровня A1–C2**: грамматика, лексика, чтение и аудирование (озвучка через синтезатор речи браузера).
  Вопросы усложняются по уровням и заканчиваются, когда на уровне больше половины ошибок.
  Можно ввести уровень вручную или баллы EF SET.
- **Результат**: уровень, прогресс до следующего, навыки и темы с ошибками.
- **Программа на 8 недель** под цель, время в день и число дней в неделю: уроки и тренировки по слабым темам,
  карточки слов с интервальным повторением, аудирование, чтение, говорение и письмо, контрольные тесты на 4-й и 8-й неделе.
- **Практика**: 39 тем с правилами на русском, работа над ошибками, свои слова.
- **Отчёт для Claude**: результаты, ошибки и цель одним текстом — вставить в чат, чтобы доработать программу или проверить текст.

Данные хранятся на устройстве (localStorage), есть резервная копия в JSON.
Установка на iPhone: открыть `…/english/` в Safari → «Поделиться» → «На экран „Домой“».
