# new-york
## Кошелёк — `wallet/`

Личный учёт расходов (PWA): счета с балансами, траты за период по каждому счёту,
бюджеты по категориям с дневным лимитом, подписки и регулярные платежи, статистика.
Данные хранятся на устройстве (localStorage), есть резервная копия в JSON и выгрузка в CSV.

Установка на iPhone: открыть `…/wallet/` в Safari → «Поделиться» → «На экран „Домой“».
